# Geist fonts

These are the exact, unmodified WOFF2 bytes downloaded by `next/font/google`
for this application's previous successful Next.js 16.4.3 production build.
Both Geist and Geist Mono retain their original 100–900 variable weight range,
Unicode subsets, display mode and fallback metrics in `src/app/geist-fonts.css`.
Only the delivery path changed. No new font design or version was substituted.

Upstream: https://github.com/vercel/geist-font

License: SIL Open Font License 1.1, included in `OFL.txt`.
The SHA-256, size and original CSS declaration for every file are recorded in
`manifest.json`. The two Latin subsets are preloaded, as in the original build.
Other subsets load on demand. Build and runtime require no Google Fonts requests.
