# Long Term Direction

更新日: 2026-06-02

考察箱は、知識を効率よく渡すサイトではなく、夜更かしした人が帰ってくる放送局である。

## 優先順位

1. 会話品質
2. 公開面の信頼性
3. 放送室としての空気
4. 制作基盤
5. 箱シリーズへの再利用性

## 公開面の原則

- 未完成データを見せない。
- 正式公開済みエピソードだけを出す。
- 制作中のseed、draft、preview、仮音声は制作側に閉じる。
- 便利な一覧より、夜に開きたくなる状態を優先する。

## 空間演出の原則

- 声が主役。
- BGMとAmbientは脇役。
- 画面は「サイト」ではなく「部屋を覗く」感覚へ寄せる。
- CRT、ON AIR、時計、雨、暖色照明は番組の空気を作る要素として扱う。

## 箱シリーズへの見通し

将来的に以下を共通基盤化する。

- 考察箱: 深夜の知的ラジオ局
- 観察箱: 観察している部屋、記録、距離感
- よるの相談箱: 相談を受け取る静かな場所

共通化するのは「ルーム基盤」「モニター表示」「環境音」「状態表示」であり、会話品質や番組設定は各箱ごとに持つ。
