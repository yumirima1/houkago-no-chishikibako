# 放課後の知識箱 企画ストック #017〜#030

原稿生成前の候補タイトル集。

正解を教える回ではなく、深夜に二人で話したくなる違和感を優先する。

話数案: #017

タイトル: マネタイズってそんなに悪いことなのか

知識箱適性: お金、創作、応援、罪悪感が混ざるので、かなの違和感とタルタルの仕組み話が両方出しやすい。

神回候補マーク: ★

注意点: 収益化の是非を断定せず、好きなものを続けるための現実として扱う。
