# 3Dルームの窓・音・家具（2026-10-27）

これは10月27日時点の実装記録です。現在の部屋・スマートフォン表示・音声操作は
[10月28日の改修仕様](ROOM_REDESIGN.md)を参照してください。

既存のNightStudy、CRT端末、机、福岡市の天候、街並みと電車を保った改修。
保存API・データベース・考察の生成処理は変更しない。

- 右の窓枠とガラスを左にスライドさせる引き違い窓。クリックと、折り畳み
  「部屋の音と窓」パネルのボタンが同じ状態を操作する。通常は補間し、
  reduced-motionでは即時に移動する。雨粒も各ガラスと一緒に動く。
- 部屋を見渡すカメラに引き、ベッド、オフィスチェア、PC本体、2枚目の
  モニター、別置きのブラウン管テレビを追加。既存CRTもモニターとして維持。
  本の高さはGLBの棚上面から計算。縦長の電子ペーパーポスター2枚を段違いに配置。
- 屋外だけを窓の開口のステンシルに限定し、縦画面で街が屋根の上へ出るのを防ぐ。
- 音はWeb Audioで実際に合成する。既存BGMファイルは未保有のため参照しない。
  オリジナルの72 BPMのコード・ベース・キック・ハイハットによるローファイループ、
  雨のノイズ、遠い交通音を模した低域ノイズを使用。第三者の録音・サンプル・
  音楽配信サービス・外部音声リクエストは使用しない。音は実地録音ではない。
- 初期状態は全停止、AudioContextもユーザーの再生操作まで生成しない。
  3系統の再生・停止・音量は独立。音量ゼロは短いランプの後に正確な0となる。
  窓の開閉では外音バスだけを0.22〜1へ550msでフェードし、ローパスも
  850〜12,000Hzへ変える。音楽には影響しない。雨音の選択は実天候とは独立。
- context.resumeの失敗を表示し、再試行可能。開始直後の停止も世代番号で保護。
  画面終了時に音源とコンテキストを解放。再読み込み後は自動再生しない。

## 検証

`npm ci --ignore-scripts --no-audit --no-fund`、型チェック、Lint、通常の本番ビルド、
Pages用ビルド、`scripts/verify-pages-artifact.mjs` を実施。
音声ユニットテストは独立制御、正確な無音、窓のバス、再試行、開始中の停止、
PCMの有限性・音量を確認する。

`tests/pages/room-controls.spec.ts` は既存のPlaywright設定でローカルと公開に共用。
実際のAudioContext/GainNode/AnalyserNodeをテスト側で観測し、出力波形が非ゼロに
なること、ゼロ音量で無音になること、窓で音楽のgainが変わらないことを確認。
加えて窓の3Dクリック、CRT起動/終了、再読み込み、再生失敗、390×844表示と
キーボード操作を検証する。天気APIは通信モックにし、外部の天候変動から分離。
人によるスピーカーでの試聴評価を代行するテストではない。

公開方式は既存の `.github/workflows/pages.yml` を維持。mainへの通常pushで
型・Lint・全テスト・静的成果物・ブラウザ検証を通してGitHub Pagesに配信する。
Vercelの既存ルーティングも維持し、同じ部屋は `/observer-room` にある。
