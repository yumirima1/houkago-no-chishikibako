# 放課後の知識箱 自動制作ロードマップ

## 方針

v0.x は公開済みの静的サイトを維持しつつ、AI制作パイプラインを後から接続できる形にする。ログイン、DB、課金、RSS、外部配信連携は必要になるまで入れない。

## 目標フロー

1. 管理者がテーマを入力する
2. AIが初稿を作る
3. 別AIが校閲する
4. 会話形式へ整える
5. 理系担当と文系担当で音声生成する
6. SEとエンディングを含めて1つの音声に統合する
7. `public/audio` と `src/data/episodes.ts` に反映して公開する

## 優先順位

- #0 を「まずこれを聴く」として最新回とは別枠で固定表示

## データ設計メモ

当面は `src/data/episodes.ts` を正とする。将来の自動公開では、生成済みの音声ファイルとエピソードメタデータを同じ単位で扱えるようにする。

必要になりそうな追加項目:

- `scriptPath`
- `reviewPath`
- `productionStatus`
- `sourceTheme`
- `voices`
- `generatedAt`
