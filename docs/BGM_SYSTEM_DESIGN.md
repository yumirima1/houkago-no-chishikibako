# 放課後の知識箱 BGMシステム設計メモ

## 目的

放課後の知識箱は知識サイトではなく、夜更かしした人のための小さな放送局です。
BGMは主役ではなく、タルタルとかなの会話を「夜の放送局」に置くための薄い空気として扱います。

## 基本方針

- 会話音声を最優先にする。
- BGMは聞こえるか聞こえないかの境界に置く。
- 雨音、部屋鳴り、時計、遠い環境音と競合しない帯域にする。
- 1曲を目立たせず、番組全体の灯りとしてループできる設計にする。
- 実装初期はユーザーが明示的にオンにできる形を優先する。

## 著作権

- 商用利用可能、再配布可能、配信利用可能な音源だけを使う。
- YouTubeや配信サイト由来の「フリーBGM」は、利用規約が変わる可能性があるため原則避ける。
- 推奨は自作、正式ライセンス購入、または CC0 / 明示的な商用利用可ライセンス。
- 音源ごとに `docs` または `content` 配下へ出典、ライセンス、取得日、利用条件を記録する。
- 生成AI音源を使う場合も、利用サービスの商用利用条件と再配布条件を記録する。

## 音量バランス

- 会話音声を 0 dB 基準とし、BGMは初期値で -24 dB から -30 dB 程度を目安にする。
- 雨音を入れる場合、雨音は BGM よりさらに薄くする。
- 低域が強いBGMは長時間視聴で疲れやすいため避ける。
- 声の明瞭度を下げる 1kHz から 4kHz 付近の強い音は控える。
- ユーザー側で BGM / 雨音を個別にオフにできる設計にする。

## フェード

- 番組再生開始時、BGMは 3〜6秒かけてフェードインする。
- 一時停止時、BGMは即停止ではなく 1〜2秒でフェードアウトする。
- シーク時は一度薄くして、音声再開後に戻す。
- エピソード切り替え時は前のBGMをフェードアウトし、次のBGMをフェードインする。

## 番組終了後

- エピソード終了後は、BGMをすぐ止めず 8〜15秒だけ残してからフェードアウトする。
- 自動連続再生が有効な場合は、BGMを完全停止せず薄く保ち、次の回へ自然につなぐ。
- スクリーンセーバー状態では、終了後に時計と背景だけが残る状態を許可する。

## 雨音との共存

- 雨音は背景モードの一部として扱い、BGMとは別トラックにする。
- 雨の夜は雨音を少し強め、星の夜と曇りの夜は雨音を切るか極小にする。
- 雨音はループ継ぎ目が分かりにくい 60秒以上の素材を推奨する。
- 雨音とBGMを同時に鳴らす場合、BGMはさらに -3 dB ほど下げる。

## 将来の実装案

- `public/bgm/` に公開用BGMを置く。
- `public/ambient/` に雨音などの環境音を置く。
- `content/audio-profiles/` にエピソードタグとBGM/環境音の対応を保存する。
- `useAmbientAudio` のようなフックで、再生状態、フェード、音量、ミュートを一元管理する。
- `localStorage` に BGM音量、雨音音量、ミュート状態を保存する。
- 初期状態ではBGMオフ、または非常に小さい音量から始める。

## 避けること

- 会話より目立つメロディ。
- ループ感が強い短い音源。
- 著作権状態が曖昧な素材。
- 動画背景と一体化した重いBGM実装。
- 自動再生制限を回避しようとする実装。
