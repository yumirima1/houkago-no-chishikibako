# Observation Box Integration

更新日: 2026-06-04

## 目的

観察箱を、通常のリンク一覧ではなく、部屋の中のオブジェクトとして統合する。

## 現在位置

Room Mode 内に「観察端末」を置く。

観察端末は次を扱う。

- 観察ログ
- 観察対象の現在行動
- 放送ネタになりそうな思考
- future theme source への接続点

Phase 2では Observation Log から `broadcastHint` / `themeCandidate` を残す土台を追加した。

これは自動生成の入口ではなく、次の放送テーマ候補を人間が確認するための保留棚である。

## 配置候補

タルタルの部屋:

- CRT横の小型端末
- 配線の間に置かれた観察ログ装置
- 机上のメモ保存機

かなの部屋:

- ランプ横の小型ラジオ
- 日記の横に置かれた観察箱
- 窓際の小さな記録端末

## 扱い方

観察箱はUIメニューではない。

部屋にある物として扱う。

```txt
部屋のオブジェクト
  ↓
観察ログ
  ↓
broadcastHint / themeCandidate
  ↓
放送ネタ
  ↓
theme source
```

## Subject別の意味

同じオブジェクトでも、タルタルとかなでは意味を変える。

- CRT / 小さなラジオ
  - タルタル: 画面、NOW PLAYING、放送機材、考える距離。
  - かな: 声の距離感、返事しなくていい安心。
- メモ / 日記
  - タルタル: 放送テーマ未満の違和感。
  - かな: ちゃんとした質問になる前の疑問。
- 窓
  - タルタル: 外の時間と作業速度。
  - かな: 外の現実感と部屋の中の不安。
- ランプ
  - タルタル: 作業に戻る合図。
  - かな: 暗さを少し残す安心。

## 禁止

- 観察箱を単なるリンク集にする
- タルタルとかなを同じ部屋に住ませる
- 観察対象をマスコット化する
- dependency を重い依存演出にする
