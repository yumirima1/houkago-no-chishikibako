# Observation Box Integration

更新日: 2026-06-04

## 目的

観察箱を、通常のリンク一覧ではなく、部屋の中のオブジェクトとして統合する。

## 現在位置

今回の実装では、Room Mode 内に「観察端末」を置く。

観察端末は次を扱う。

- 観察ログ
- 観察対象の現在行動
- 放送ネタになりそうな思考
- future theme source への接続点

## 配置候補

タルタルの部屋:

- CRT横の小型端末
- 配線の間に置かれた観察ログ装置
- 机上のメモ保存機

かなの部屋:

- ランプ横の小型ラジオ
- 日記の横に置かれた観察箱
- 窓際の小さな記録端末

## 扱い方

観察箱はUIメニューではない。

部屋にある物として扱う。

```txt
部屋のオブジェクト
  ↓
観察ログ
  ↓
放送ネタ
  ↓
theme source
```

## 禁止

- 観察箱を単なるリンク集にする
- タルタルとかなを同じ部屋に住ませる
- 観察対象をマスコット化する
- dependency を重い依存演出にする
